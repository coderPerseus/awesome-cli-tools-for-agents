# Awesome CLI Tools for Agents

A simple list of CLI tools that can help AI agents handle files, code, data, media, web pages, and automation tasks.

## Files and Directories

- [`eza`](https://github.com/eza-community/eza): Modern `ls` replacement for reading directory structure, permissions, and Git status.
- [`Mole`](https://github.com/tw93/Mole): File and directory analysis tool for quickly understanding project file distribution and content overview.

## Code Analysis

- [`shellcheck`](https://github.com/koalaman/shellcheck): Shell script linter that helps reduce common mistakes in generated or edited shell scripts.
- [`diffx`](https://github.com/wong2/diffx): Structured diff viewer for understanding code changes and file differences more clearly.

## Data Processing

- [`jq`](https://github.com/jqlang/jq): JSON querying and transformation tool for handling API responses, logs, and configuration files.

## Documents and Conversion

- [`pandoc`](https://github.com/jgm/pandoc): Document converter for Markdown, HTML, DOCX, PDF, and many other formats.

## Images and Media

- [`pngquant`](https://pngquant.org/): Lossy PNG compressor for reducing image file size.
- [`ffmpeg`](https://github.com/FFmpeg/FFmpeg): Audio and video toolkit for transcoding, frame extraction, trimming, merging, and audio extraction.
- [`svgo`](https://github.com/svg/svgo): SVG optimizer for cleaning and compressing SVG assets.

## Web and Network

- [`lighthouse`](https://github.com/GoogleChrome/lighthouse): Web quality audit tool for performance, accessibility, SEO, and best practices.
- [`agent-browser`](https://github.com/vercel-labs/agent-browser): Browser automation tool for operating web pages, inspecting page state, and running end-to-end checks.

## Other

- [`gh`](https://github.com/cli/cli): GitHub CLI for querying issues, pull requests, CI, releases, and automating GitHub workflows.
- [`Hyperconsciousness`](https://github.com/louis030195/hyperconsciousness): Developer-alpha Rust CLI for storing and retrieving encrypted append-only agent notes, with an MCP server and scoped, expiring access grants.
